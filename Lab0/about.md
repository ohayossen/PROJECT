Что такое Git? Git - это программа, которая помогает хранить историю изменений в файлах.
В чём разница между централизованными и распределёнными системами контроля версий?

Централизованная:
1) Один сервер-хранилище
2) Без интернета, нельзя сделать коммит, нельзя посмотреть историю
3) Все изменения идут через единый узел

Распределенная:
1) У каждого полная копия всей истории локально
2) Коммиты, ветки, просмотр логов - оффлайн
3) Сервер только для обмена, он не блокирует работу
